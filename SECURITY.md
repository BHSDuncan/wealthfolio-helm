# Security reporting

Do not include credentials, financial data, kubeconfigs, private endpoints, raw request bodies, or exploit details in public issues.

Use GitHub private vulnerability reporting when it is available. If it is not available, open an issue requesting a private contact without disclosing the vulnerability.

Report application vulnerabilities through [Wealthfolio's security policy](https://github.com/wealthfolio/wealthfolio/security/policy). Report chart or installer vulnerabilities to this project. See [security guidance](docs/security.md) for credential, storage, network, and image limitations.

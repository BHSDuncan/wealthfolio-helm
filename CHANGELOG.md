# Changelog

## 0.1.0 — unreleased

- Initial community chart for Wealthfolio 3.11.0, using the official image pinned by digest.
- Single non-root application instance with retained persistent storage and external authentication credentials.
- Guided installation for SSH-accessible K3s, local K3s and explicit Kubernetes contexts, with optional HTTPS or private localhost access.
- Optional authenticated MCP access, strict values validation, and chart/installer integration checks.
